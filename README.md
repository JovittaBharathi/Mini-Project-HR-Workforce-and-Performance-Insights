📊 Human Resource Workforce and Performance Insights (2020–2025)

Tools: Power BI | Excel | DAX | Power Query | Data Modelling

Domain: Human Resources | Workforce Analytics

📘 Project Overview

This project analyzes HR data from 2020–2025, focusing on employee demographics, attrition trends, performance distribution, salary patterns, experience levels, and training insights.
Using Excel and Power BI, the dataset was cleaned, modeled, and visualized to uncover key workforce trends and actionable HR insights.

The dashboards help HR teams make informed decisions related to retention, performance management, compensation, and workforce planning.

🎯 Project Objectives

*Analyze Workforce Demographics  
Study age groups, gender distribution, education levels, and job roles.

*Evaluate Attrition Trends  
Identify high‑risk departments, roles, and employee segments.

*Assess Salary & Compensation Patterns  
Compare income distribution across departments and experience levels.

*Understand Performance Distribution  
Analyze performance ratings and their relationship with experience and income.

*Study Training & Development Metrics  
Evaluate training hours and identify skill gaps.

*Support HR Decision‑Making  
Provide insights for retention strategies, promotions, and workforce planning.

📂 Data Sources

Source: Dataset obtained from UCI Machine Learning Repository & Google Dataset Search

📑 Attribute Details

| Attribute Name        | Data Type      | Description |
|-----------------------|----------------|-------------|
| Employee ID           | Integer        | Unique identifier for each employee |
| Age                   | Whole Number   | Employee age |
| Gender                | Category       | Male / Female |
| Department            | Category       | HR, Sales, R&D, Finance, etc. |
| Job Role              | Text           | Specific role within the department |
| Education Level       | Category       | Graduate, Post‑Graduate, etc. |
| Experience (Years)    | Whole Number   | Total years of experience |
| Monthly Income        | Currency       | Employee salary |
| Training Hours        | Whole Number   | Annual training duration |
| Performance Rating    | Whole Number   | Standard rating scale |
| Leave Days Taken      | Whole Number   | Total leave days taken |
| Attendance Rate (%)   | Percentage     | Employee attendance percentage |
| Attrition             | Category       | Yes / No |
| Work Shift            | Category       | Day / Night / Rotational |
| Promotion Eligibility | Category       | Yes / No |
| Income Summary        | Category       | Low / Medium / High |
| Experience Category   | Category       | Junior / Mid / Senior |
| Attendance Policy     | Text           | Attendance rule applied to employee |

🔧 Data Preprocessing Steps

*Data Collection  
Gathered HR data from internal sources (2020–2025).

*Data Consolidation  
Combined multiple sheets and standardized column names.

*Automation (Excel Macros)  
Automated repetitive formatting tasks and column alignment.

*Data Cleaning (Power Query)

*Removed duplicates

*Filled missing values

*Standardized text formats

*Corrected data types

*Data Transformation  
Added calculated columns such as income groups, experience bands, and performance categories.

*Data Integration  
Prepared a unified dataset for Power BI modeling and visualization.

📈 Workforce Insights

🟢 Sales & R&D showed higher attrition rates.

🟦 Senior employees had higher performance stability.

🟩 Employees with 3–6 years experience showed peak attrition risk.

🪙 Income increased steadily with experience across all departments.

💧 Training hours were lowest among high‑attrition groups.

📈 Gender distribution remained balanced across most departments.

💰 Finance & R&D recorded the highest average salaries.

🔚 Conclusion

The integration of Excel and Power BI enabled a comprehensive analysis of the HR dataset (2020–2025).

Key findings include:

*Clear attrition patterns across departments and experience levels.

*Strong correlation between experience and performance.

*Salary distribution highlights compensation gaps across roles.

*Training insights reveal opportunities for targeted development.

This project demonstrates how HR analytics can support data‑driven workforce decisions, improve retention, and enhance organizational performance.
